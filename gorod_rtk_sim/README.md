# `gorod_rtk_sim` — исходники симулятора организаторов

Это **чужой код**, а не наш. Сюда сложены модули симулятора полигона
«Город РТК» на IsaacLab из проекта `gorod_rtk`. Мы их не запускаем и не
правим — они лежат здесь как **источник точной геометрии полигона**.

Раньше они лежали в `регламент/` вперемешку с PDF и картинками. Разнесли,
чтобы в `регламент/` осталась только информация о соревновании, а код —
отдельно.

| Файл | Что описывает |
|---|---|
| `city_builder.py` | сетка 5×5, размеры клетки, какие клетки здания, а какие дорога |
| `road_graph.py` | граф дорог: узлы в центрах клеток, направленные рёбра |
| `lane_overlay.py` | классификация клеток и разметка полос (правостороннее движение) |
| `marking_map.py` | геометрия разметки в мировых координатах |
| `goal_points.py` | целевые точки по центрам полос на прямых участках |

## Что из этого взято в наш код

Не сам код, а **числа и правила** из него:

* [gen_city_map.py](../src/maze_nav/scripts/gen_city_map.py) — размеры
  полигона для генерации карты Nav2, сверены с `city_builder.py`;
* [route_graph.py](../src/maze_nav/maze_nav/route_graph.py) — наш граф
  маршрутов. Отличие принципиальное: у организаторов узлы стоят в центрах
  клеток, у нас — по центрам полос со смещением 0.20 м, иначе робот ездил
  бы по осевой. Классификация клеток взята из `lane_overlay.py`.

Держим их в репозитории потому, что регламент задаёт геометрию словами и
картинками, а здесь она выражена числами — сверяться с кодом надёжнее, чем
с картинкой в PDF.
