1. Проверить подключение всех проводов, вставить аккум в пищалку (tester module), вставить аккум в порт питания (желтый боковой)
Проверить правильное подключение проводов питания из Power Module: крайний левый - в Raspberry Pi, крайний правый - в Arduino. 
2. Раздать с телефона (или модема) Wi-Fi сеть со следующими параметрами:
Название сети - darkAlex
Пароль - darkAlex516
3. Включить кнопку на плате питания (Power module), убедиться в том, что светодиоды на Arduino и Raspberry Pi загорелись
4. Дождаться подключения Raspberry к раздаваемой сети, узнать ее ip в сети
5. С помощью команды ssh подключиться к Raspberry. Логин устройства - pi, пароль - raspberry (Пример команды: ssh pi@192.168.XX.XX)
6. С помощью команды cd перейти в директорию /Frob_robot/ros2/src/ros2_ws
7. В этой директории прописать команду source install/setup.bash  
8. После этого прописать команду ros2 run ros2_arduino_bridge arduino_bridge 
9. Открыть новое окно терминала. Повторить пункты 5) и 6) и 7)
10.  Теперь можете экспериментировать с помощью cmd_vel. Команда для этого:
ros2 topic pub /cmd_vel geometry_msgs/Twist "{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}"

При изменении linear.x скорости, робот начнет двигать вперед при значениях >0 и назад при значениях <0.
При изменении angular.z скорости, робот начнет поворачивать влево при значениях >0 и вправо при значениях <0.


        Не рекомендуется ставить значения больше, чем 1.0 по модулю
